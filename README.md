# ML Volatility Forecasting

## Research question

**Does Machine Learning Actually Improve Volatility Forecasting?**

This project will compare a simple historical-volatility baseline with Ridge
regression using chronological evaluation. It is a research experiment, not
investment advice.

## Initial setup

Install the project dependencies with:

```bash
python -m pip install -r requirements.txt
```

Download daily SPY historical prices with:

```bash
python src/download_data.py
```
